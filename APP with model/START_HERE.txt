⚡ QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ "Backend connection failed"
   → Make sure backend is running: npm run server

❌ "No WiFi networks detected"  
   → Run Command Prompt as Administrator
   → Ensure WiFi is enabled on your computer

❌ "Port already in use"
   → Check what's using port 5000
   → netstat -ano | findstr :5000
   → Or change PORT in server.js

❌ "App won't start"
   → Delete node_modules/ folder
   → Run: npm install
   → Try again

❌ "High latency showing"
   → This is measured to Google DNS (8.8.8.8)
   → High values = actual network issues
   → Try moving closer to WiFi router

📊 ALGORITHM EXPLAINED
═══════════════════════════════════════════════════════════════════════════════

SCORING FORMULA:
  Score = (Signal × 0.35) + (Latency × 0.30) + 
          (Loss × 0.20) + (Stability × 0.15)

SIGNAL STRENGTH (35%):
  Input: dBm (-100 to -30)
  Converts to: 0-100 score
  Better: Higher numbers (less negative)

LATENCY (30%):
  Input: milliseconds (0-100)
  Converts to: 0-100 score
  Better: Lower numbers

PACKET LOSS (20%):
  Input: Percentage (0-10%)
  Converts to: 0-100 score
  Better: Lower numbers

STABILITY (15%):
  Input: Percentage (0-100%)
  Converts to: 0-100 score
  Better: Higher numbers

FINAL RESULT: 0-100 composite score
